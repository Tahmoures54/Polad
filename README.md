# صندوق خانوادگی پولاد

اپلیکیشن موبایل Flutter برای مدیریت صندوق قرض‌الحسنه خانوادگی. فلسفه محصول: **ساده‌تر، پایدارتر و شفاف‌تر از همیان**، با کنترل نهایی در دست مدیر، معماری آنلاین-اول و کارمزد قانونی به‌صورت «هزینه خدمات نرم‌افزاری» از مدیر — نه از عضو.

## ویژگی‌ها

- ورود با شماره موبایل و OTP
- داشبورد عضو: سهم، بدهی، طلب، اقساط، ثبت پرداخت با کد پیگیری و فیش
- داشبورد مدیر: موجودی، اعضا، وام‌ها، معوقات، صف تأیید/رد
- وام قرض‌الحسنه با جدول اقساط خودکار (هزینه اداری ۲٪ صندوق، نه بهره بانکی)
- قرعه‌کشی تصادفی یا دستی
- گزارش جریان نقدی، معوقات، خروجی Excel/PDF (پریمیوم)
- چند صندوق، دعوت با کد، نقش مدیر/عضو
- صورتحساب ماهانه خدمات نرم‌افزاری برای مدیر (۰٫۵٪ تا ۱٪)
- اتصال بانکیما (بانک ملت) از طریق Cloud Functions
- خواندن پیامک بانکی روی گوشی مدیر (فقط Android)

## اجرای حالت آزمایشی (بدون Firebase)

```bash
flutter pub get
flutter run --dart-define=POLAD_DEMO=true
```

ورود آزمایشی:

| نقش | موبایل | کد تأیید |
| --- | --- | --- |
| مدیر | `09120000000` | `123456` |
| عضو | `09121111111` | `123456` |

کد دعوت نمونه: `POLAD1`

## ساخت نسخه تولید (Firebase)

1. پروژه Firebase بسازید و Phone Auth، Firestore، Storage، Functions، FCM را فعال کنید.
2. `flutterfire configure` را اجرا کنید تا `lib/firebase_options.dart` جایگزین شود.
3. قوانین را دیپلوی کنید:

```bash
firebase deploy --only firestore:rules,storage,functions
```

4. اپ را با فلگ‌های تولید بسازید:

```bash
flutter build apk --dart-define=POLAD_DEMO=false --dart-define=POLAD_FIREBASE=true
flutter build ios --dart-define=POLAD_DEMO=false --dart-define=POLAD_FIREBASE=true
```

5. اسرار بانکیما را فقط در Functions تنظیم کنید (هرگز در کلاینت):

```bash
firebase functions:secrets:set BANKIMA_CLIENT_SECRET
```

متغیرها: `BANKIMA_BASE_URL`, `BANKIMA_CLIENT_ID`, `BANKIMA_CLIENT_SECRET`

## مدل درآمد و انطباق شاپرک

طبق بخشنامه شاپرک، کارمزد درصدی **از تراکنش عضو صندوق قرض‌الحسنه گرفته نمی‌شود**. پولاد مبلغ ۰٫۵٪ تا ۱٪ را به‌عنوان **هزینه خدمات نرم‌افزاری** فقط برای مدیر صندوق جمع می‌کند و در صورتحساب ماهانه نشان می‌دهد. مبلغ واریزی عضو کامل به موجودی صندوق می‌نشیند.

صندوق خیریه می‌تواند درگاه با کارمزد صفر (طرح نیکوکاری) داشته باشد.

نسخه رایگان: ۱ صندوق و حداکثر ۱۰ عضو. پریمیوم: چند صندوق، عضو نامحدود، خروجی Excel/PDF.

## معماری

- Flutter 3.47 + BLoC/Cubit
- آنلاین-اول با کش Hive برای نشست و دادهٔ اخیر
- عملیات مالی حساس فقط در Cloud Functions
- قوانین Firestore بر اساس عضویت صندوق (نه custom claim سراسری) تا یک کاربر بتواند مدیر یک صندوق و عضو صندوق دیگر باشد
